# Bhopal Impact Lab 2026: problem statements and data

Claude Impact Lab × Cerebras Café Compute, Bhopal · Sunday 11 October 2026 · SSR Global Skills Park

Today you build a working tool for a real Bhopal problem, in one day, with Claude and Claude Code. Everything you build is open source and offered to the Government of Madhya Pradesh through MPSeDC.

This repo has both problem statements, the data for each track, the original source documents and all the links.

## The two tracks

| | Track 1: Bhumi Vikas Sahayak | Track 2: Visarjan Ghat Watch |
|---|---|---|
| In one line | Ask the Bhopal building rulebook and get an answer with the rule number | Turn three years of ghat water tests into a risk warning before Durga visarjan |
| User | Building-permission clerk, Bhopal Municipal Corporation | BMC officer planning Durga visarjan at the ghats |
| Data | 105 rules from the MP Bhumi Vikas Rules 2012, split and page-referenced | 1,524 water-test readings at 7 Bhopal ghats, 2023 to 2025 |

Citizens ask in English, Hindi and Hinglish, and the official Hindi PDF uses an old font that can't be reliably extracted. - Trust matters. A generic AI chatbot can make up rules or numbers. In a government office, a confident wrong answer is worse than no answer. Our solution Bhumi Vikas Sahayak is an AI assistant for the counter clerk, built on Claude. It answers from the official rulebook and nothing else. - Fast answers in the citizen's language. The clerk asks in plain English, Hindi or Hinglish, typed or spoken. The answer comes back in seconds with a short summary the clerk can read out. - Answers you can verify. Every answer shows the rule number, PDF page and exact quote. Each quote is checked against the actual PDF page, and the rulebook opens side by side at the cited page. - No more misread tables. Tables are rebuilt as clean, readable tables with the exact row highlighted, and calculations are shown step by step. - Version awareness. Every answer states the rule version it's based on, and an amendment alert warns when Rule 2(5)(c) applies. - Honest when unsure. The tool says clearly when the rules don't cover a question. When two rules conflict, it shows both instead of guessing. - Something to take home. One click sends a branded PDF report and WhatsApp message to the citizen, with no paid API. Our principle "The tool points to the rule; the clerk decides." Bhumi Vikas Sahayak is not legal advice. It makes the clerk faster and more confident, and every answer can be checked against the rulebook. |
